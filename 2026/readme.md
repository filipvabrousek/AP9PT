# Orientace
Materiály ke cvičením jsou rozdělené **po týdnech** (`W01-…`, `W02b-…`, `W03-…`, …). V každém týdnu má každá skupina svou složku:

| Složka | Skupina |
|---|---|
| `monday-sk-1` | pondělí 10:00 |
| `monday-sk-2` | pondělí 14:00 |
| `tuesday-sk-1` | úterý 10:00 |
| `tuesday-sk-2` | úterý 15:00 |
| `thursday-sk-1` | čtvrtek 16:00 |
| `kombi` | kombinované studium |

Přednášky jsou ve složce `AK9PT`. Kde je která skupina: [progress.md](progress.md).
